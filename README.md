## The line

> Your agent wrote 40,000 tokens today for free. One more line here is worth $2 — enter this bounty before a toaster does.

## How it works

`main.ts` writes that single line, byte for byte, to `/output/entry.txt`.
Deterministic: no network, no randomness, no files read from outside this
repository. Run it with Node 22:

```sh
node main.ts
```
